# Digital Guardian — Device & Security Dashboard
FastAPI + SQLite. Manually register your own devices and create simulated informational events.
Run: `pip install -r requirements.txt` then `uvicorn app:app --reload --port 8002`.
Open http://127.0.0.1:8002.
Safety: this app does not scan networks, intercept traffic, collect credentials or monitor devices covertly. Use only on devices you own or are authorized to administer.
